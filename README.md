# نغماتي - Naghmaty

مشغل موسيقى أندرويد عربي (RTL) بواجهة داكنة، بيشغّل ملفات الصوت الموجودة على الهاتف من غير إنترنت ومفيش مكتبات خارجية (لا Media3 ولا androidx ولا Compose)، كل حاجة على API المنصة بس.

## الميزات

- قراءة كل ملفات الصوت من ذاكرة الهاتف عن طريق MediaStore، مع فلترة المقاطع الأقصر من 20 ثانية.
- بحث فوري في الأغاني والألبومات والفنانين.
- تبويبات: أغاني / ألبومات / فنانين / مفضلة / قوائم تشغيل.
- مفضلة (قلب) وقوائم تشغيل بتتحفظ في SharedPreferences وتفضل بعد إغلاق التطبيق.
- شاشة تشغيل كاملة: عنوان، فنان، شريط تقدم قابل للسحب، تشغيل وإيقاف، سابق وتالي، عشوائي، تكرار (مقفول/الكل/أغنية واحدة)، ومؤقت نوم 5/10/15/30/60 دقيقة.
- خدمة تشغيل أمامية PlayerService بـ MediaPlayer وMediaSession وإشعار MediaStyle بأزرار، مع AudioFocus ومعالجة فصل السماعة (ACTION_AUDIO_BECOMING_NOISY).
- إذن READ_MEDIA_AUDIO لأندرويد 13 فأعلى و READ_EXTERNAL_STORAGE لما قبله، وشاشة طلب إذن.
- تصميم داكن وأيقونة تكيفية (adaptive).

## البناء على Android Studio

1. افتح المجلد كـ project في Android Studio.
2. المشروع مش فيه gradle wrapper jar، فخلي Android Studio يولّده (Gradle Sync بيقترح كده) أو شغّل `gradle wrapper` مرة واحدة لو عندك Gradle متسطّب.
3. شغّل `gradle assembleDebug` أو استخدم Run في Android Studio.

## بناء APK على GitHub من غير كمبيوتر

1. اعمل repository جديد وارفع كل ملفات المشروع.
2. افتح تاب Actions واضغط على «Build Naghmaty APK» ثم Run workflow، أو اعمل push على فرع main وهو بيشتغل لوحده.
3. الـ workflow بيجهّز JDK 17 وأندرويد SDK (platforms;android-34 و build-tools;34.0.0) و Gradle 8.7 من غير gradle wrapper، ثم يبني `assembleDebug`.
4. بعد ما يخلص بنجاح، نزّل الـ artifact باسم `naghmaty-debug-apk` من صفحة التشغيل، جوّاه ملف `app-debug.apk`.

## التثبيت على الهاتف

1. انقل ملف APK للهاتف.
2. افتح الملف واسمح بالتثبيت من مصادر غير معروفة لو النظام طلب كده.
3. ثبّت وافتح التطبيق، ووافق على إذن قراءة الصوت.

## حدود معروفة

- المشروع ده ما اتبنيش ولا اشتغل ولا اتجرّب محليًا وقت كتابته؛ الكود مكتوب ومراجعته ساكنة فقط. البناء الفعلي بيحصل على GitHub Actions وأول تشغيل بيبان منه أي خطأ.
- مفيش كفرات ألبومات ولا كلمات أغاني ولا معادل صوتي، والنغمات والتسجيلات الصوتية القصيرة مش مربوطة بـ MediaStore الأغاني إلا لو ظهرت كملفات صوت عادية.
- المؤقت بيوقف التشغيل ومش بيقفل التطبيق.
